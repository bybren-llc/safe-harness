# Product requirements (template)

Copy this file. Leave unused rows blank. Do not fill this template in place.

## How this relates to spec.md

A PRD is optional. Use it when a change needs longer product context than `spec.md` should carry.

- `spec.md` stays canonical for requirement IDs.
- When a PRD item becomes a tracked requirement, give it a `REQ-<CMP>-NNN` ID under `requirements/` and point that file at a `spec.md` (or `intent.md`) anchor.
- `FR-` and `NFR-` codes below are PRD citations only. They are not registry IDs. Map each one to a `REQ-<CMP>-NNN` when the requirement is registered.
- Reviewers cite the short codes in this file (G-, NG-, U-, D-, FR-, NFR-, PH-, A-, Q-, RK-).
