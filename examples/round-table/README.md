# bybren-llc/safe-harness Instance Specifics

This directory holds the maintainers' own filled versions of template files, plus instance-specific decisions and metrics. Adopters use these as examples only.

## Contents

- `intent.md` - Filled intent (the maintainers' version)
- `spec.md` - Filled spec (the maintainers' version)  
- `link-health.md` - Link rot detection spec (the maintainers' routine)
- `linear-saf-map.csv` - Linear→GitHub migration map (frozen archive)
- `metrics.md` - M1-M6 metrics for shipping safe-harness v1.0
- `decisions.md` - Instance decisions (O4-O6, environment, non-goals)

## For Adopters

These files show what filled templates look like. Your repo will have:
- Your own `intent.md` and `spec.md` at the root (see those files for the adopter template format)
- Your own success metrics defined in `spec.md` or `constitution/00-north-star.md`
- Your own decisions recorded in `docs/decisions/`
